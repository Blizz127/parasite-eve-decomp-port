# Phase 6E-B43: `func_8005218C`

## Verdict and translation boundary

`func_8005218C` is classification 1: understood translated retail
resource-table/record derivation logic. B43 selected architecture B,
prefix-only translation, because its then-unresolved first dependency had a
required output-state effect that the centralized boundary could not invent.

B44 subsequently translated `func_8005B91C` from its complete retail body.
The production B43 prefix now executes all seven exact output calls and all
seven translated `func_8005DBAC` consumers. If the record-holder path is
active, it continues through the `func_80052F24` call delay slot, commits the
retail `record+0x26` halfword, and stops at that still-unresolved callee. The
instruction after the call is not executed. If the holder or selected record
is null, the existing retail early return remains exact. The actual Disc 1
state takes the null-holder path; no fixture forces it to `func_80052F24`.

## `func_8005B91C` B43 audit and B44 resolution

- Executable `0x8005B91C..0x8005BA77`, file offset `0x4C11C`.
- Size `0x15C`, 87 instructions.
- Live `asm/disc1/4C0A8.s:51-151`, nonmatching.
- Conceptual retail signature:

```c
void func_8005B91C(int32_t table_number, int32_t key,
                   pe_addr_t index_out, pe_addr_t fraction_out);
```

It calls translated `func_8005DB8C(table_number)` once.  That leaf reads the
corrected guest word `0x800A8038` and returns the selected 0x200-byte table
base.  `5B91C` performs a signed binary search beginning at index 64 with
step 32, halving the signed step until zero. It can directly read signed
words from `base` through `base+0x200`, depending on the key/table. It
selects/clamps the final index to at most 98, optionally computes and caps a
signed interpolation fraction at 48, writes the selected index as a 32-bit
word through nonzero `a2`, and writes the fraction through nonzero `a3`.
It has no hardware, BIOS, SDK, callback, host-time, polling, or blocking
behavior and is deterministic from guest state and arguments.

There is one epilogue and no early return.  With `a3==0`, its residual `v0`
is `(selected_index < 98)`; with `a3!=0`, the final branch delay leaves
`v0=48`.  All 18 executable calls ignore this residual return.  The complete
caller census is:

## `func_80052F24` read-only boundary audit

- Executable `0x80052F24..0x80052F6F`, file offset `0x43724`.
- Size `0x4C`, 19 instructions.
- Live `asm/disc1/43724.s:12-33`, nonmatching.
- Sole caller: B43 at `0x800523C4`.
- Conceptual signature: `void func_80052F24(int32_t value)`.

It signed-compares `value < 51`, clamping only values 51 or greater to 50;
negative values are stored modulo 256.  It writes exactly one byte at
`0x800C0E0C`, reads authoritative `$gp+0x2D8 = 0x8009D048`, and compares it
with guest address `0x800C0E48`.  On equality it calls translated
`func_80052F70()` and writes that exact return to authoritative
`$gp+0x2E0 = 0x8009D050`.  Otherwise it makes no authoritative write.  It is
deterministic, nonblocking retail logic with no platform/SDK activity.

Its residual `v0` is either `0x800C0E48` on the no-call path or the exact
`func_80052F70` result; B43 ignores and overwrites it.  Its byte write and
conditional host-authoritative write are nevertheless required retail
state, so a boundary cannot silently continue past it. After B44 the B43
production prefix reaches it only on non-null-holder paths and stops there.

### Direct footprints

Transient stack accesses cover the output word at `incoming_sp-0x20` and
the saved registers at `incoming_sp-0x10`, `-0x0C`, and `-0x08`.  The output
word is `new_sp+0x10`.  Native C uses a full-width host local for this
transient word and never stores it to guest RAM.

Fixed direct guest reads are seven signed halfwords `0x800C0E28..34`, words
`0x800A1B30..44`, word `0x8009D254`, the word it designates, halfword
`0x800C0E08`, and byte `0x800C0E0A`.  Fixed direct writes are halfwords
`0x800C0E06` and conditionally `0x800C0E08`.

Data-dependent reads are the seven `5DBAC` returned records at offsets
`+0`, `+2`, `+4`, `+8/+C/+10`, `+14/+16`, `+6`, and `+7`.  Data-dependent
direct writes through the selected destination record are exact sparse
fields `+4,+C,+E,+1C,+1E,+20,+22,+26,+28,+2C,+30,+3C,+3E`; widths are
halfword except words `+28/+2C/+30`.  The minimum possible dynamic direct
read/write address is determined by the unbounded retail guest pointer; no
pointer or size is clamped.  Checked port accesses reject invalid ranges.
The exact fixed read minimum is `0x8009D254`, maximum `0x800C0E34`; fixed
write minimum is `0x800C0E06`, maximum exclusive `0x800C0E0A`.
